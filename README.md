### Brew & Bloom Café ☕
A responsive café website built with HTML5 and CSS3, featuring a warm, modern café design.

**Features:**
- Responsive layout for desktop, tablet, and mobile
- Hero, About, Menu, Gallery, and Contact sections
- Responsive navigation
- Café-themed UI and typography
- Hover effects and smooth scrolling

**Technologies:** HTML5, CSS3

**Live Demo:** https://devv-sabanaz.github.io/Brew-Bloom/
